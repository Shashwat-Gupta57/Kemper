Features

Small app.
Works everywhere.

Set a combo once and it types in Word, Chrome, Discord, VS Code, games: anywhere you can type.

⌨

Set a combo like in a game

Click the key box, press the keys, type what they should produce. Done.

✦

Any text at all

Symbols, accents, emoji, other scripts or whole sentences, with any keyboard layout.

⌕

Forgot a combo? Pick it

The quick picker pops up all your shortcuts by the mouse. Search, press Enter, and it's typed.

!

Clashes can't slip through

Two shortcuts on the same keys turn red, and Kemper won't save until you fix them.

◐

Quiet in the background

Starts when you sign in if you like. Closing the window keeps your shortcuts working.

›_

A full command line

Add, remove and check shortcuts from a terminal, or run Kemper with no window at all.

Get started

Up and running in a minute.

You need Python 3.10 or newer. Pick your system:

Download kemper.pyw

It's the whole program. Keep it in a folder where it can stay, like C:\Tools\Kemper.

Install pywebview

The one library Kemper's window needs:

python -m pip install pywebview

Double-click it

Click Add Shortcut, press a combo, type its text and click Save. Turn on Start with Windows if you like.

Download kemper.pyw

It's the whole program. Keep it in a folder where it can stay, like ~/Applications/Kemper.

Set it up and start it

In Terminal, in that folder:

python3 -m venv ~/.kemper ~/.kemper/bin/pip install pywebview pynput ~/.kemper/bin/python kemper.pyw

Allow keyboard access

Allow Input Monitoring and Accessibility in System Settings → Privacy & Security, then start Kemper again.

Download kemper.pyw

It's the whole program. Keep it in a folder where it can stay, like ~/kemper.

Install and start (Ubuntu)

In a terminal, in that folder:

sudo apt install python3-venv python3-gi gir1.2-webkit2-4.1 xclip python3 -m venv --system-site-packages ~/.kemper ~/.kemper/bin/pip install pywebview python-xlib ~/.kemper/bin/python kemper.pyw

Use an Xorg session

Global hotkeys need X11. At the login screen, click the gear and pick Ubuntu on Xorg.

Something not working? python kemper.pyw --doctor checks your setup and says how to fix it.

Command line

Prefer a terminal?

Everything the window does works from the command line too, and changes reach a running Kemper right away.

  • --add, --remove, --keys manage shortcuts
  • --cli runs Kemper with no window
  • --doctor finds problems and explains the fix
> python kemper.pyw --add "Alt+2" "²" Added Alt + 2 → ² > python kemper.pyw --keys Alt + 2 → ² Alt + Shift + 2 → ₂ > python kemper.pyw --doctor ✓ Python 3.12.10 ✓ Shortcuts are active ✓ Kemper is running All good.
