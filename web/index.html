Any character.
One key combo.

Kemper, short for Key Mapper, types the character or text you choose whenever you press a key combo, in every app on Windows, macOS and Linux. Alt + 2 gives ². Ctrl + Alt + E gives €.

Features

Small app. Every app.

Kemper sits quietly in the background. Set a combo once and it works in Word, Chrome, Discord, VS Code, games, everywhere you can type.

⌨

Set a combo like in a game

Click the key box, press the keys, type what they should produce. Done.

!

Clashes can't slip through

Two shortcuts with the same keys turn red, and Kemper won't save until you fix them.

✦

Any text at all

Symbols, accents, emoji, other scripts, whole sentences. It works with every keyboard layout.

◐

Light and dark

Follows your system, or pick a side. Starts when you sign in if you like, and closing it doesn't stop it.

Quick picker

Forgot the combo? Pick it.

Press Ctrl + Alt + K anywhere and all your shortcuts pop up by the mouse, like Win + V does for the clipboard.

  • Type to search by character or combo
  • Enter or click to type it into the app you were in
  • Drag it out of the way by its top strip
Keypacks

Share your shortcuts.

A keypack is a set of shortcuts in one .kmppck file: Greek letters, math, arrows, your team's phrases. Double-click one and Kemper shows exactly what's inside before anything changes.

Clashes with your shortcuts Takes over keys like Ctrl + C Already in your Kemper

Make your own in the Keypack Editor

  • Import from your Kemper through a gallery, with Select all
  • Add, Remove, Undo and Redo across your last 50 changes
  • Export with a name, a file name and a folder
  • Safe to receive: every keypack is checked, and nothing is imported without asking
Made by AI

Describe it. Get a keypack.

ChatGPT, Claude, Gemini or any other AI chat can write keypacks for you. Give it Kemper's instructions, say what you want, and paste its answer into the Keypack Editor.

“Greek letters for math, capitals on Shift” “Arrows on Ctrl + Alt + arrow keys” “My email signature on Ctrl + Alt + S” “Subscript digits for chemistry”

Get started

Up and running in a minute.

You need Python 3.10 or newer. Pick your system:

Download kemper.pyw

It's the whole program. Put it in a folder where it can stay, like C:\Tools\Kemper. When installing Python, tick “Add python.exe to PATH”.

Install the window's one library

Open a terminal and run:

> python -m pip install pywebview

Double-click kemper.pyw

Turn on Start with Windows and Desktop shortcut if you want them, then click Add Shortcut, press a combo, type its text and click Save.

Download kemper.pyw

It's the whole program. Put it in a folder where it can stay, like ~/Applications/Kemper.

Set it up and start it

In Terminal, in that folder:

python3 -m venv ~/.kemper ~/.kemper/bin/pip install pywebview pynput ~/.kemper/bin/python kemper.pyw

Allow keyboard access

macOS asks for Input Monitoring and Accessibility. Allow them in System Settings → Privacy & Security, then start Kemper again. Turn on Start at login if you like.

Download kemper.pyw

Install what it needs (Ubuntu)

In a terminal, in that folder:

sudo apt install python3-venv python3-gi gir1.2-webkit2-4.1 xclip python3 -m venv --system-site-packages ~/.kemper ~/.kemper/bin/pip install pywebview python-xlib ~/.kemper/bin/python kemper.pyw

Use an Xorg session

Global hotkeys need X11. At the login screen, click the gear and choose Ubuntu on Xorg. Then turn on Start at login and Desktop shortcut if you like.

Command line

Prefer a terminal?

Everything the window does works from the command line too. You can even run Kemper with no window at all.

  • --add, --remove, --keys to manage shortcuts
  • --cli to run with no window, logging each shortcut you use
  • --doctor to check your setup and say how to fix it
> python kemper.pyw --add "Alt+2" "²" Added Alt + 2 → ² > python kemper.pyw --keys Alt + 2 → ² Alt + Shift + 2 → ₂ > python kemper.pyw --doctor ✓ Python 3.12.10 ✓ Shortcuts are active ✓ Keypack files (.kmppck) open in Kemper All good.
